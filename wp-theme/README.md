# めぐるHP制作 — WordPress テーマ

`hp/`（静的版のめぐるHP制作）を WordPress のテーマにしたもの。見た目と動き（オープニング、「YM」の島、イラスト、スクロールの演出）は静的版と同じ。

ページは **ブロックエディタ**（WordPress の標準の編集画面）で作る。
このサイトのデザインの部品が「めぐる」のブロックとして入っていて、見た目のまま文字をクリックして直したり、＋で足したり、ドラッグで並べ替えたりできる。

## 入れ方

1. `wp-theme/meguru.zip` をダウンロードする（GitHub でファイルを開いて「Download raw file」）
2. WordPress の管理画面 → 外観 → テーマ → 新規追加 → テーマのアップロード で zip を選び、有効化する
3. 有効化すると、自動で次のものができる
   - 固定ページ「トップページ」（中身はいまのトップと同じブロック一式。設定 → 表示設定 の「ホームページ」に設定される）
   - 固定ページ「これまでのこと」（スラッグ `history`）
   - 固定ページ「お知らせ」（投稿の一覧。表示設定の「投稿ページ」に設定される）
   - お知らせの見本1件、「実績」のはじめの2件（サムネイル画像つき）
4. 設定 → 一般 で「サイトのタイトル」を `めぐるHP制作`、「キャッチフレーズ」を `柳沢恵瑠` にする（ブラウザのタブや検索結果のタイトルになる）
5. 設定 → パーマリンク を「投稿名」にする

## 管理画面でできること（クライアントに伝えること）

| やりたいこと | 場所 |
| --- | --- |
| ページの文字・写真を直す | 固定ページ → ページを開く → 文字をクリックしてそのまま書き換え。写真はブロックを選ぶと出る「写真を選ぶ」 |
| セクションを足す・消す・並べ替える | 左上の「＋」→「めぐる」のブロックを選ぶ。並べ替えはブロックの ↑↓ かドラッグ、削除は「⋮」→ 削除 |
| ページを丸ごとひな形から作る | ＋ →「パターン」→「めぐる」→「トップページ一式」「経歴ページ一式」 |
| お知らせを書く | 投稿 → 新規投稿を追加。トップの「お知らせ」と「お知らせ」ページに新しい順に並ぶ |
| 実績を追加・編集・並べ替え | 左メニューの「実績」。タイトル＝サイト名、アイキャッチ画像＝サムネイル（横長 16:10）、「実績の情報」＝種類とURL、「ページ属性」の順序＝並び順 |
| 検索結果に出る説明文 | ページの編集画面の右 →「抜粋」。SEO のプラグイン（SEO SIMPLE PACK など）を入れたときは、そちらが優先 |
| ロゴの文字、右上のボタン、フッター、メールアドレス | 外観 → カスタマイズ → めぐるHP制作 |
| ファビコン | 外観 → カスタマイズ → サイト基本情報 → サイトアイコン |
| ふつうのページ（プライバシーポリシーなど） | 固定ページを作って、段落・見出し・画像などのふつうのブロックで書く。同じ緑のテイストで表示される |

**文章の書き方**

- 見出しは、改行（Shift + Enter）したところで行が分かれて、1行ずつ下からせり上がる
- 本文はふつうの段落ブロック。Enter で段落が増える
- イラストは、ブロックを選んで右のサイドバー「写真・イラスト」から選ぶ。写真を選ぶと、イラストの代わりに写真が出る

## 「めぐる」のブロック

| ブロック | 中身 |
| --- | --- |
| ファーストビュー（YMの島） | 動くイラストの上にキャッチコピー。このブロックがあるページだけ、オープニングと島のアニメーションが動く |
| 大きな文章 | 大きな文章と、右下の小さな文章 |
| 大きな写真 / 写真2枚 | 横いっぱいの写真、ずらして並べる2枚 |
| 章（大きな一言＋文章） | 縦書きの一言と見出し・本文。写真（イラスト）を付けると3列。サイドバーで一言を右にもできる |
| 写真の上を通る言葉 | 画面いっぱいの写真の上を、大きな言葉が通り過ぎる |
| 囲み（特集） | 白い囲みに見出し・写真・本文。比べる図（○○ → 0円）と緑の帯はサイドバーで出し入れ |
| 実績の一覧 | 「実績」に登録したもの。PC では横に流れる |
| プロフィール | 縦長の写真と、名前・自己紹介 |
| お知らせ（新着） | 投稿の新しいもの。件数はサイドバーで |
| お問い合わせ（しめくくり） | 大きな見出しと本文。`{mail}` のところにメールアドレスのリンクが入る |
| ページの最初（見出し＋写真） | 下層ページのいちばん上 |
| 章（番号＋写真） | 番号・一言・ラベル・本文と横の写真。サイドバーで写真を右にできる |
| 年表（ステップ） | 緑の線の上に段ごとに並ぶ。中の「ステップ」を＋で足す |

公開ページの HTML は `inc/blocks.php` の `meguru_render_*` が出す（静的版と同じクラス名・同じ形）。
編集画面の見た目と入力欄は `assets/editor/blocks.js`。最初の中身とパターンは `inc/content.php`。

## ファイル

```
meguru/
  style.css            テーマの名前など（WordPress が読む）
  functions.php        CSS・JS の読み込み、タイトル・説明文・OGP、カスタマイザー
  inc/blocks.php       「めぐる」のブロックの登録と、公開ページの HTML
  inc/content.php      最初の中身（いまの文章）と、パターン「トップページ一式」「経歴ページ一式」
  inc/works.php        「実績」の登録と入力欄
  header.php / footer.php
  page.php             固定ページ（最初が「めぐる」のブロックなら、ページ名の見出しは出さない）
  single.php           お知らせ1件
  index.php            お知らせの一覧・検索結果・見つからないページ
  assets/editor/       ブロックエディタ用（blocks.js、editor.css）
  assets/css/main.css  ← hp/style.css のコピー
  assets/css/wp.css    WordPress 用の追加分（お知らせ、ふつうのページ、管理バー）
  assets/js/*.js       ← hp/ の JS のコピー
  assets/images/       ← hp/images のコピー
```

## hp/ を直したとき

CSS・JS・画像は `hp/` からのコピー。`hp/` を直したら、次を実行するとテーマにも反映され、`meguru.zip` も作り直される。

```bash
./wp-theme/build.sh
```

文章は WordPress の管理画面で直す（`hp/` の HTML とはつながっていない）。
`hp/` の HTML の形（クラス名など）を変えたときは、`inc/blocks.php` の render と `assets/editor/blocks.js` も同じように直す。

※ `wp-theme/` はメインサイトの Worker では配信しない（ルートの `.assetsignore` に書いてある）。
